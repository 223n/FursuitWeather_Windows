## 何を作るか

デスクトップへ置きっぱなしにして、着ぐるみで活動してよい状況かを目の端で確かめられるものを作ります。
表示する面は2つです。

- 壁紙の上に置く、枠の無い半透明の小窓
- タスクトレイへの常駐と、判定が悪くなったときのトースト通知

Windows 11のウィジェットボード（`Win`+`W`で開くパネル）への対応は、要件から外しました。
外した経緯は[技術選定](stack.md)にあります。

判定そのもの（暑さ指数の計算、レベルの判定、連続活動時間の算出）は本体のAPIが行います。
このクライアントは受け取ったJSONを描くだけです。
判定の仕組みを知りたい場合は、本体の[判定ロジック](https://github.com/223n/FursuitWeather/blob/main/docs/logic.md)を見てください。
